# MPR Lessons Results Hub (Apps Script)

`Code.gs` is the Apps Script bound to the "MPR Lessons Results Hub" Google Sheet, owned by the contact@mprstudios.com Google Workspace account.
It is NOT deployed by GitHub Pages; this folder is only a source copy. Edit in the Apps Script editor and keep this file in sync.

Update rule: Deploy > Manage deployments > pencil > Version: New version > Deploy.
Never 'New deployment' (that changes the /exec URL).
